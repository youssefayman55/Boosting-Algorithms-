🧠 Overview

This repository contains a collection of Machine Learning projects using Boosting Algorithms, implemented in Python using Jupyter Notebooks.

The goal of this project is to explore and compare different boosting techniques for both classification and regression tasks, including:

1-AdaBoost

2- XGBoost

3- CatBoost

Each algorithm is implemented, trained, and evaluated on different datasets to demonstrate performance differences.

⚙️ Algorithms Covered

🔹 AdaBoost (Adaptive Boosting)

1- Ensemble method that combines weak learners into a strong classifier

2- Focuses on correcting misclassified samples iteratively

🔹 XGBoost (Extreme Gradient Boosting)

1- Highly optimized gradient boosting framework

2- Known for speed, performance, and scalability

🔹 CatBoost

1- Gradient boosting algorithm designed to handle categorical features efficiently

2- Reduces need for heavy preprocessing
